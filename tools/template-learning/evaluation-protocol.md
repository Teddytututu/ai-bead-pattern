# FT0 评测协议 v1

> 本文件保留旧 v1 尺寸／角色任务的实验约定。2026-09-30 起新目标为[区域生成与 adapter 评测](../../docs/plans/bead-facial-template-learning-plan.md#5-评测与通过条件)，本文件的模板指标不能代替新模型验收。新协议尚未在工具中实现。

本文件冻结首轮方法与阈值，审核者和独立设计分组尚待确认；这不代表 FT0 全部通过。`prepare` 中 reviewer=null、split=unassigned，不能自动把助手目视检查当作人工金标准。

## 分母、监督与切分

候选预算：138 张确认脸／眼、62 张其他动漫、40 张动物；配额不足如实记录，不跨类补数。所有失败、范围外和未知项保留在总体分母。PNG 像素大小不是格数；来源页面声明仅作 declaredScope，不作为 verifiedScope。

原设计、近似设计、身份／角色、左右眼和镜像／换色／缩放版本先归组，再冻结 FT1 约160/80的开发／封存分组。FT2 目标60/20/20；FT1 封存组不进入训练或验证。当前只有精确哈希和来源分组提示，不据此宣称近似去重已完成。测试组不得进入检索库、阈值选择或训练统计。

审核者在开发组约24例上复核完整面板、方格/六角布局、格距相位、白珠/空白、左右、可见性、角色、紧致宽高、局部/全图锚点；歧义保留 unknown。宽高包含所有功能格及必要内部保留格，不留人为外圈 padding。多解显式列 acceptableSizes。保存原预测、差异、标注版本、复核者、耗时。人工目标与模型输入物理分开。

## 冻结阈值

| 项目 | 首轮门槛 |
| --- | --- |
| 读格 | 自动接受方格的占用/颜色索引一致率 ≥99%，逐图统计，白珠/空白单列 |
| 预标注 | 接受候选 precision ≥95%，可见且可表达部件 recall ≥80%；附覆盖与全部失败 |
| 成本 | 同难度组预标注+校正的耗时中位数较纯人工下降 ≥30% |
| 尺寸 | 主目标组可接受尺寸率 ≥90%，宽/高绝对误差 P90 各 ≤1 格；单格单列 |
| 结构 | 共同格坐标功能格 F1 ≥0.90；角色宏F1、稀疏角色、锚点、边界、尺寸错误单列 |
| 合法性 | 导出尺寸等于预测尺寸，边界/角色/锚点/预算通过；非法及拒绝候选仍进入报告 |
| 最终五官 | 眼 Top-2 ≥90%，嘴 ≥85%，可表达硬特征完整可见率 ≥95%，硬碰撞0 |
| B类改善 | 对开发集冻结的主要基线盲评，按来源组 bootstrap 的净胜差95%区间下界 >0，硬约束不退化 |

没有独立人工标签时指标为未测，不用模型分数、beadCount 总数吻合或合成单元测试替代准确率。读格不可靠时暂停模板导出；分割不可靠时记录失败或转人工框/点模式，不镜像补齐、手写语义分割。

## 对照与兼容

B0直接提取、B1现有35规则模板、B2训练组检索；M0局部+学习尺寸、M1全图+固定/框尺寸、M2全图+学习尺寸、D0审定尺寸/证据诊断。固定同一输入、分析、色卡、画布、用色预算和候选上限4；同时报告Top-1。不得在封存集选最弱对手。

共同坐标由输入查询和预测锚点放置，不拉伸矩阵或搜索最佳对齐来消除错误。原始预测与最终放置分别计分。主验证自行预测尺寸，D0只作诊断。A重建和B真实转换分开报告。

保留30个独立人物输入与32/48/64格回归，加入动漫、独立眼、倾斜、闭眼、遮挡、多脸、矩形。96格走原流程。通用24/Perler123/MARD291分别报告颜色、结构、可见性、回退、速度、显存；样本不足标证据不足。

## 资源及停止条件

单进程、batch=1、并发=1，单次模型烟测300秒超时，自动重试0；试验目录预算2GiB，金标准目标24，单例人工预算15分钟。后两项是审核/扩批前检查值，当前准备命令不自动强制人工计时或对外声称已测性能。冷加载与推理失败分开保存；烟测只报告进程冷启动总耗时及模型内部耗时，不当作稳定吞吐。

来源未明确、无真值、分组泄漏或不可恢复读格错误时不训练；审核积压或资源超预算时暂停扩批。B改善不足、全图/自主尺寸未证明或硬约束退化时不默认发布。FT2–FT5及产品总计划均不因工具就绪自动完成。
