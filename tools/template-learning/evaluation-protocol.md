# 读格与审核证据的评测边界

本文件由 prepare 复制到新运行，说明该工具输出能够支持哪些判断。已冻结运行仍使用包内原协议及哈希，不随此文件重写。

## 统计单位

来源图片、原设计、派生视图和部件不是同一种样本。一张图的三视图预标注不能算成三个独立设计。镜像、改色、缩放及近似构图先审核分组，再划分开发、验证和测试。

声明格数与人工审定格数分开；所有失败、未知、范围外项目保留分母。PNG 尺寸、豆数吻合或模型置信度不等于读格正确。

## 当前可检查内容

| 对象 | 检查 |
| --- | --- |
| 来源与文件 | 清单覆盖、图像解码、内容哈希、使用资格 |
| 读格 | 面板位置、格距、相位、颜色索引与白珠／空板 |
| 部件证据 | 实例归属、可见性、漏检、坐标映射 |
| 人工审核 | 审核者、版本、未确认项、原预测及差异 |
| 分组 | 近似设计和身份关联，不只依赖文件哈希 |
| 数据包 | 冻结配置、契约、工具与产物哈希可对应 |

有独立人工真值时才计算精度、召回、逐格一致性和人工耗时。没有真值的项目标为未测，合成夹具不能替代真实效果。

## 使用限制

工具尚不自动建立合格训练配对，prepare 的 trainingAllowed 为 false。旧模板宽高、角色预测或规则模板比较不再作为产品验收目标；不从本目录报告推导第二阶段网络准确率。

新的 256 卡通图到 32／64 网格评测必须另建配对数据、固定基线、来源分组和验收标准，见 [训练路线](../../docs/training.md)。冻结审核包及其原始日志是证据，清理普通执行日志时保留。
