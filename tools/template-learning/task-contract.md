# 历史审核文件契约

本文件说明当前工具仍可读取的 template-learning-v1，执行定义为 [contracts.py](contracts.py)。其角色候选结构用于历史文件校验，不表示项目保留规则模板生成能力，也不是新的第二阶段网络输出合同。

## 坐标和数据

- 单位为格，完整图 W／H 各 1–64，左上原点、x 向右、y 向下、行优先。
- 框是半开区间，锚点是整数格索引。超范围设计保留范围外状态，不缩图冒充审定全图。
- wire 保存完整未 padding 的 RGB 和占用；白珠为占用，空板不占用，未知为 null。
- tensorize 向右／下补至 64×64，padding 的 valid=false，不等同于有效空板。
- segmentationEvidence 仅为预测证据，实例关系和源图到格图的映射需一致。
- 输入和 Target 独立保存，未知字段拒绝；目标尺寸和人工真值不混进预测输入。

## 兼容校验

旧 GenerationOutput 支持每查询 1–4 个带宽高、角色矩阵、局部／全图锚点及置信信息的候选，或带原因的 no_template。校验矩阵长度、画布边界、占用、锁定、保护和相邻约束，不改变预测尺寸以通过检查。

preserve-base 表示保留原格底色；它不是白珠、孔洞或 padding。监督允许 unknown，输出不允许。maximumColors 是材料预算，角色数不能代替材料色数。

## 冻结与迁移

prepare 保存来源、配置、代码、契约及初始产物哈希，生成的训练清单为空。后续阶段记录各自输入和结果，不回写旧运行。

新标注、卡通目标和网格配对采用各自明确的协议。迁移需保留旧文件和映射记录，不能改 schema 名称就声明旧角色标签等价于新监督。当前方向见 [训练路线](../../docs/training.md)。
