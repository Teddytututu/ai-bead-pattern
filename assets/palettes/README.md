# Material Palettes

通用材料色卡资源目录。首版提供 `generic-24.json` 作为算法演示和测试色板，品牌色卡接入时继续保留显示 RGB 与实体 Lab 两套字段。

`mard-291.json` 提供 MARD 291 色的字母+数字色号、屏幕参考 RGB、HEX 和分组信息。数据来自公开的 [pindou-color-data](https://github.com/HansBug/pindou-color-data) 仓库 `mard-291-github/colors.json`，按 MIT 数据许可保留来源与 revision。RGB 仅用于屏幕和算法参考，生产配色仍应以实体色卡校准。
