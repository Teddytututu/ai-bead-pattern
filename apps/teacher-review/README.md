# 标注操作说明

1. 打开 http://127.0.0.1:4190 ，选择最新生成轮次。
2. 在“图片序号”输入一组连续 25 张，例如 0-24 或 450-474，点击“应用”。可用“上一组 / 下一组”切换。编号固定为 000–499，动物为 000–249，动漫脸为 250–499。
3. 对照原图选择：仅 A 合格、仅 B 合格、两张都合格、两张都不合格。标准是卡通风格，同时保持主体轮廓、五官、姿态和主要颜色不失真。两张通过时再选偏好；两张都不合格时，勾选“颜色”和/或“姿态”（至少一项），原因一同写入 JSONL。
4. 必要时修正英语描述、填写备注，点击“保存并下一张”。快捷键 1/2/3/4 选择，Enter 保存，方向键翻图。先保存再切换范围。
5. 本组 25 张全部标完后自动导出，例如 000_024.jsonl 或 450_474.jsonl；不足 25 张也可点“导出本组标注 JSONL”。手动导出同样按当前范围命名；未完成时只包含已标注项。修改后重新导出仍用范围名称，后台另存版本。文件内 photo_id 对应照片编号。
6. 默认仅显示已生成的待标注图。“本组进度”可区分未生成与已标注；查看或修改旧标注时，把状态改为“全部”或“已标注”。

新轮次输出为 256×256 等比缩放，白色补边。高分辨率底稿可点击查看。

编号图片在 output/teacher-loop/dataset-numbered/images/000.jpg 至 499.jpg，本地与 SSH 相同；manifest.json 保留旧编号映射，已有标注和生成任务可继续使用。

标注先保存到 SSH；自动导出后页面也提供下载链接。整轮结束后备份图片与标注：

    pwsh -NoProfile -File scripts/dev/teacher-review.ps1 -Action backup -Scope all

完成审核后才使用页面下方“冻结已通过标注 → 用快照训练 LoRA → 创建下一轮”。只有合格训练集目标进入训练，验证集和测试集不参与。
