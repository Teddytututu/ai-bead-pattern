# 教师卡通图审核

本页面审核“原图 → 256×256 卡通图”，独立于产品工作台和眼睛目标标注。通过 teacher-review.ps1 建立 SSH 转发后，默认访问 http://127.0.0.1:4190。

## 审核一组图片

1. 选择生成轮次和编号范围，例如 0–24；使用“上一组／下一组”切换。
2. 对照原图与 A/B，选择仅 A 合格、仅 B 合格、两张合格或两张都不合格。
3. 主要检查身份、主体轮廓、五官、姿态和主要颜色。更卡通不等于合格。
4. 两张合格时选择偏好；两张都拒绝时按页面要求填写颜色／姿态原因，可用备注补充其他问题。
5. 必要时修改描述，点击“保存并下一张”。先保存再切换范围。
6. 一组全部审核后自动导出范围命名的 JSONL；也可手动导出当前已审核项。

快捷键 1／2／3／4 选择结果，Enter 保存，方向键翻图。默认列表只展示已生成的待审核图，切换“全部／已标注”可回看。

当前准备工具将照片编号为 000–499，其中动物 000–249、动漫脸 250–499；实际条目以服务器清单为准。新轮次预览为等比补边的 256×256，可查看对应高分辨率底稿。

## 保存与后续训练

标注先保存到 SSH 服务。导出包含拒绝项、数据划分、路径、哈希及标注版本；JSONL 不包含图片字节。修改后再次导出生成新版本，不覆盖旧记录。

整轮结束后备份图像、审核库和输出：

~~~powershell
pwsh -NoProfile -File scripts/dev/teacher-review.ps1 -Action backup -Scope all
~~~

“冻结 → 训练 LoRA → 新轮次”用于已获准的训练任务；只有通过审核的 train 目标进入训练，validation／test 不参与。合格样本数只是启动条件，不能代表模型质量已经达标。详细实现与恢复见 [Teacher Loop](../../tools/teacher-loop/README.md)。
