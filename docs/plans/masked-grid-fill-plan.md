## 固定流程

1. **先周边**：先用现有工作台生成完整拼豆图，选择可改区与锁定格，检查周边图案和配色。从有效蒙版外提取全图材料与两格邻域色调，建议底色色号；用户可指定当前材料集合中的肤色。冻结图纸、色卡、蒙版、底色选择及生成参数，返回上下文指纹。
2. **再蒙版区**：保留原来的肤色底图逻辑。完整拼豆图的周边保持不变，蒙版内预铺与周边协调的肤色，再把完整图与二值 mask 交给 SDXL。这里没有灰色或透明占位区域。SDXL 自身的 masked-image latent 分支仍按标准 inpainting 流程处理 mask。
3. **完整填充与协调**：从模型输出逐格填满有效区域，包括原来的空格；在材料集合内量化。以周边可见格估计的颜色漂移作有限修正，并对周边已有材料给予柔性优先。周边与锁定格直接复制，局部修复不能导致全图重新配色。
4. **检查再接受**：空格、透明残留、无变化候选不能交付。“结构修复”另拦截四格及以上区域的单色／低对比结果；“色调协调”允许合理纯色填充。失败按固定种子序列最多三次，仍失败则不提供可接受候选，保留原图与原因。
5. **接受与导出**：检查眼型、表情、配色和边界，填写原因后接受。材料数量随填充重算，可撤销。可改区仍有空格时禁止导出完成图；回放文件可保存失败草稿。

“不留空”覆盖指定的可编辑蒙版范围；图案外原有空板不自动铺满。蒙版内的空格若被锁定，需先解除锁定，不能静默跳过。自动建议的底色仅是邻域主要材料，不是肤色语义识别；用户需核对或指定。结构检查也不能替代人工判断五官是否正确。

任何请求输入变化后指纹失效，必须重走第 1 步。第二步必须携带与当前输入匹配的准备指纹。程序诊断按同样顺序运行，其准备事件不能冒充人工确认。
