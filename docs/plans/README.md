## 当前基线

- **色卡与配色**：Perler 123 已接入现有生成、API/SDK、统计和导出；MARD 协调性与 Perler 取色／细节缺陷已修正。三套色卡的完整真实质量门禁仍待完成，Perler 参考 RGB 尚非实物测色。
- **自动分析与五官**：GroundingDINO Tiny + SAM 2.1 Small 已接入，35 个规则模板及姿态放置、点选校正已有实现；本批图纸的分图效果与模板学习尚未验证。
- **图纸数据**：已下载 2,435 张有效图纸，确认动漫脸部 115 张、眼部 23 张；题材审核、部件真值和训练资格是不同状态，不能据下载量宣告训练就绪。
- **后续交付**：纹理保护、预览色号开关、完整逐格／画布编辑和本期集成验收仍按总计划推进；Perler 的编辑器联动随 P6/P7 完成。

## 当前工作顺序

1. **近期方案入口：五官专项 FT0 → FT1。** 固定模型、全图输入／可变尺寸输出契约及评测协议，随后用约 240 张候选图纸验证逐格还原、≤64×64 格资格、分图与尺寸真值和人工校正成本。候选数量不等于合格数量；当前只完成计划，试验尚未开始。
2. **并行准备：配色质量门禁 P1/P8。** 在已修复基线上扩展人物、宠物与插画的真实样本及分区对照，为后续训练冻结质量基线；不重复实施已有色卡接入或已修复缺陷。
3. **试验通过后：FT2 → FT3。** 建立保留完整图案的配对数据、审定宽高与矩阵及来源分组，冻结直接提取、规则、检索和固定尺寸对照；不要求先训练另一个排序模型。训练继续满足总计划 P9 适用的基线、数据资格与三套色卡评估要求。
4. **核心生成与验收：FT4 → FT5。** 训练“完整图案＋预测分图 → 自主宽高＋角色矩阵”的模型，验证全图与尺寸学习的贡献，再完成接口、真实转换效果和回退验收。成品图纸重建和真实输入改善分开报告。若收益不足可停止试验并保留基线，但不能将基线成果算作生成模型交付。
5. **总体产品主线继续保留。** P4 纹理、P5–P7 编辑与 P10 整体验收使用总计划排期；五官专项不代表参数策略、全局候选排序或完整编辑器已完成。

图纸解码和分割可行性试验可独立于编辑器开展；进入训练与默认发布时，再按对应阶段的门禁验收。

## 维护规则

- 总计划维护 P0–P10 状态，专项维护 FT0–FT5 细项；完成专项子阶段不自动勾选整个 P9。
- 状态区分“待实施”“首批实现／待质量验收”“完成”；“用户历史验收通过”只适用于已有明确确认的范围。
- 状态变更附实现提交或验证记录，表格和检查表同步；计划中的目标、建议数量和阈值不能改写成实测结果。
- 初始设计、旧缺口与失败审计移入 `archive/` 并注明时点；当前仍有效的要求留在总计划或专项中。
- 优先保留现有文件路径与阶段编号；移动文档时同步检查相对链接和标题锚点。
