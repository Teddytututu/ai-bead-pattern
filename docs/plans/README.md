## 当前基线与缺口

- **色卡与配色**：24／MARD 291／Perler 123 已接入；MARD 协调性与 Perler 取色／细节缺陷已修正。完整真实质量门禁仍待完成。
- **自动分析**：GroundingDINO Tiny + SAM 2.1 Small 已接入，35 个规则模板及姿态放置、点选校正已有实现。它们提供分析／比较基线，不是本次要求的生成式模型。
- **旧数据准备**：2,435 张图纸、240 候选、24 例读格／三视图预标注、分组建议及角色审核页已有。预标注只在 6/24 图得到眼候选，无鼻／嘴候选；人工真值与独立分组未完成，训练资格为 0。
- **新路线**：SDXL Inpainting 已装配；[v3 运行契约](../region-generation-v3.md)固定“先确认周边与配色 → 蒙版铺肤色 → 局部生成”。完整填充、锁定保护、失败重试、接受／拒绝、撤销与导出已实现。LoRA 单步、基础 UNet 冻结和保存／重载通过；正式训练未启动，旧图库训练资格仍为 0。
- **硬件与质量**：RTX 4070 Laptop 8GB 已通过 512/1024 推理及 512 rank-4 LoRA 单步测试。旧 v2 缺眼无变化失败保留；最新肤色底图样例填满 41 格、补齐 20 个空格，周边／锁定格零修改，但眼型、高光仍未通过质量验收。正式训练分辨率和三色卡效果待验证。

## 当前工作顺序

1. **FT0／FT1：扩展零训练验证。** 保持完整拼豆周边＋蒙版肤色底图输入，验证局部结构与协调性；任何参数或蒙版变化都重新确认周边。扩大真实样例，保留无变化、单色和语义失败。2026-10-01 更正：训练与推理均只使用拼豆格图，不再计划附加原照片／插画条件。
2. **FT2：独立训练标注前端。** 2026-10-01 最新方案：只在完整拼豆格图中框选眼睛目标、取肤色并填写 prompt，一次确认全部并封存，不修改目标图。工作台蒙版用于辅助定位，不能直接当作训练标签；训练仍停止。
3. **FT3／FT4：对照后仅训练 adapter。** 固定肤色底图流程，比较无／有 adapter、协调强度和工作分辨率；不引入原照片／插画条件，蒙版只定义在完整拼豆格图坐标中。主干冻结，原版 v1 工具不冒充新生成接口。
4. **FT5：产品接入与三色卡验收。** 最终格图接受度、范围／锁定、姿态、色数与资源同时验收；96 格走现有流程，直到新路线另行覆盖。
5. **产品其他主线继续。** P1/P8 质量门禁、P4 纹理保护、P5–P7 编辑与 P10 整体验收保留；专项调研完成不代表 P9 或整体验收完成。
