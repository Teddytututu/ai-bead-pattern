# 从绘画过程到拼豆图纸：生成方法论

查询日期：2026-08-15

## 核心定义

拼豆生成可以定义为：

> 在固定网格、真实材料色卡和有限信息容量下，重新组织原图的构图、结构、明暗与颜色。

输入照片提供内容与身份特征，输出图纸服务于实体制作。系统的目标包含主体辨识度、像素造型、材料配色和制作体验。

这一定义带来三个工程判断：

1. 构图、结构和信息预算先于最终色号分配。
2. 眼睛、嘴、脸型、耳朵与身份花纹进入统一的重要性地图。
3. 每颗豆的颜色由全图色板和区域色组共同决定。

## 1. 绘画过程提供的组织原则

传统绘画与数字绘画常采用从整体到局部、从粗形到细节的推进方式。构图、比例、结构和大明暗关系先建立，局部纹理与修饰随后加入。

绘画过程研究也呈现相近顺序：

```text
Plan → Sketch → Inspect → Refine
规划 → 粗稿 → 检查 → 局部修整
```

拼豆生成可以沿用这一层级关系：

| 绘画阶段 | 系统任务 | 阶段产物 |
|---|---|---|
| 构图 | 确定主体位置、裁剪范围和画布尺寸 | `CanvasPlan` |
| 起形 | 建立主体轮廓、语义区域和关键点 | `UnderstandingResult` |
| 大关系 | 分配特征格数、明暗层级和区域色组 | `FeatureBudget`、`ColorPlan` |
| 深入 | 栅格化眼、口、耳、花纹和轮廓转折 | `FeatureConstraintMap` |
| 修整 | 整理孤立豆、长条、毛刺和局部配色 | `GridEditRecord[]` |

前一阶段的结果作为后一阶段的约束。网格资源由高优先级特征先行分配，低优先级纹理根据剩余容量压缩。

## 2. 像素画阶段的表达规律

像素画与普通绘画共享构图、比例、结构和色彩关系。两者在低分辨率信息压缩阶段形成明显差异。

像素画的基本表达单元是具有形状意义的 `pixel cluster`。同色像素组成眼睛、发梢、衣褶和轮廓转折；孤立像素、随机抖动和破碎边缘容易形成视觉噪声。

极低分辨率下，普通缩放与逐格平均容易带来三类问题：

- 关键特征落入同一格，人物身份信息被压缩。
- 轮廓经过平均后变软，方格造型缺少清楚的转折。
- 摄影纹理占用有限格数，大结构获得的表达资源减少。

更合适的过程为：

```text
原图理解
  ↓
形状与身份特征筛选
  ↓
低分辨率结构重排
  ↓
像素簇与轮廓修整
```

抗锯齿和抖动在拼豆中转化为少量过渡色豆。每一颗过渡色都应承担明确的轮廓、明暗或材质作用。

## 3. 人类绘画行为与算法模块

| 人类绘画行为 | 像素表达 | 算法候选 | 拼豆用途 |
|---|---|---|---|
| 决定主体和构图 | 主体占据合适画布比例 | 显著性检测、主体分割 | 去背景、裁剪、画布候选 |
| 测比例和关键位置 | 五官与姿态获得独立格组 | Face / Pose Landmark | 保护眼、口、脸型、耳朵和身体比例 |
| 铺设大形 | 建立大像素簇 | SLIC、区域合并、图像抽象 | 压缩摄影纹理，形成稳定色块 |
| 归纳明暗 | 每个区域使用二至三档明暗 | 区域分割、Retinex、Intrinsic Image | 区分固有色与结构性暗部 |
| 设计色彩 | 建立有限 color ramps | CIELAB、CIEDE2000、全局色板优化 | 从真实材料色卡联合选色 |
| 整理轮廓 | 控制阶梯、转折和簇形 | 边缘检测、轮廓优化、局部搜索 | 修整脸型、头发、衣服和宠物轮廓 |
| 进入固定网格 | 每格承担单一离散状态 | 可控像素化、离散优化 | 生成 `H × W` 拼豆图纸 |
| 完成局部修图 | 清理碎点、断线和坏簇 | 连通域、形态学、图优化 | 提升制作稳定性和整体观感 |
| 选择成品方案 | 比较多套合法画法 | 成对偏好学习 | 排序各类尺寸、风格和颜色方案 |

## 4. 拼豆带来的实体约束

拼豆图纸比屏幕像素画多出材料与制作约束：

- 每格对应一颗真实豆子。
- 每颗豆子属于固定品牌、色号和材料类别。
- 透明、金属、夜光与普通实色各有表现特点。
- 颜色数量、总豆数和碎片结构影响制作成本。
- 屏幕参考色与实体颜色存在测量差异。

最终网格采用离散变量：

```text
x(i, j) ∈ {C1, C2, ..., Cn}
```

其中 `Ci` 来自当前项目允许使用的真实材料色卡。优化目标可以写成：

```text
L =
  λstructure × Lstructure
+ λfeature   × Lfeature
+ λedge      × Ledge
+ λcolor     × Lcolor
+ λvalue     × Lvalue
+ λcluster   × Lcluster
+ λcraft     × Lcraft
```

各项分别衡量主体结构、关键特征、轮廓、材料颜色、明暗顺序、像素簇和制作复杂度。

## 5. 七阶段生成流程

### Stage A：画面规划

识别主体、构图、显著区域、人脸或身体关键点，并生成 32×32、48×48、64×64 等候选画布。

输出示例：

```text
画布：48×48
主体占比：80%
重点：脸部与眼睛
背景：低优先级
制作成本：2304 颗豆以内
```

### Stage B：信息保护

根据目标格数建立 `ImportanceMap` 和 `FeatureBudget`。人物重点通常依次为眼睛、嘴、脸型与发型、鼻子、身体轮廓；宠物重点通常依次为眼睛与鼻子、耳朵、脸部轮廓、代表性花纹和身体姿态。

眼睛参与画布评分和特征预算，画布尺寸同时考虑主体完整度、轮廓空间、构图平衡与制作成本。

### Stage C：结构抽象

使用主体分割、语义分割、超像素、轮廓和区域合并，将摄影图像组织为：

```text
大轮廓 + 大区域 + 少量身份特征
```

这一阶段决定哪些形状进入最终网格，并为五官、耳朵、花纹等高优先级特征预留位置。

### Stage D：明暗与颜色设计

每个语义区域先估计固有色，再将区域内部相对明暗压缩为二至三档：

```text
皮肤：亮部 → 基础肤色 → 阴影肤色
头发：高光 → 固有色 → 深色
衣服：亮部 → 固有色 → 结构性暗部
```

随后从真实拼豆色卡中联合选择全图颜色。色差、明暗顺序、相邻区域对比、关键特征对比和颜色总数共同进入目标函数。

### Stage E：离散网格生成

`StructurePlan`、`FeatureConstraintMap` 和 `ColorPlan`
共同约束每个格子的色号。SD-πXL 提供了与这一形式接近的研究基线：
固定 `H × W` 网格，每格从有限元素集合中选择一个离散类别，
并展示了 fuse beads 等实体应用。

### Stage F：像素簇修整

规则与局部搜索处理以下结构：

- 单格孤立豆和极小连通域
- 一格宽长条与断裂轮廓
- 2×2 对角连接歧义
- 轮廓毛刺与重复折返
- 双眼、耳朵等成对特征的一致性
- 颜色过碎与局部色组跳变

### Stage G：多候选排序

系统生成少量差异清楚的候选，例如“更接近原图”“更简洁”“更鲜艳”“颜色更少”。排序分三层：

1. 工艺与关键特征硬条件。
2. 结构、配色、成本等规则评分。
3. 基于项目内成对选择数据的偏好模型。

偏好数据记录“原图 + 候选 A + 候选 B + 用户选择”，并分别询问主体辨识度、整体观感和实际制作意愿。

## 6. 模块边界

整套系统分成三层：

| 层 | 解决的问题 | 主要产物 |
|---|---|---|
| 视觉理解 | 原图包含哪些对象，哪些特征优先表达 | 主体掩码、关键点、语义区域、重要性地图 |
| 图形与优化 | 固定网格和真实色卡下如何重新表达 | 结构方案、颜色方案、离散网格、修图记录 |
| 偏好学习 | 多个合格方案中哪一版更受用户偏爱 | 候选分数、排序结果、偏好数据 |

多模态模型和扩散模型适合承担离线教师、复杂图片候选生成和研究对照。日常主流程优先采用可解释、可复现且易于评估的模块。

## 7. 研究基线与阅读顺序

| 顺序 | 研究 | 对项目的作用 |
|---:|---|---|
| 1 | [SD-πXL](https://igl.ethz.ch/projects/sd-pixl/) | 固定网格、有限元素与离散生成的直接基线 |
| 2 | [Pixelated Image Abstraction](https://pixl.cs.princeton.edu/pubs/Gerstner_2012_PIA/index.php) | 结构抽象与有限调色板联合优化 |
| 3 | [Make Your Own Sprites](https://orca.cardiff.ac.uk/id/eprint/152816/) | cell-aware 与 aliasing-aware 可控像素化 |
| 4 | [Deep Unsupervised Pixelization](https://ttwong12.github.io/papers/pixel/pixel.html) | 网格结构、锐利边缘与信息保持 |

绘画过程方向的补充资料：

- [ProcessPainter](https://arxiv.org/abs/2406.06062)：使用真实绘画过程序列学习从大形到细节的生成过程。
- [Think in Strokes, Not Pixels](https://arxiv.org/abs/2604.04746)：
  采用 Plan、Sketch、Inspect、Refine 的迭代生成结构。
- [Pixel Joint Pixel Art Tutorial](https://pixeljoint.com/forum/forum_posts.asp?TID=11299)：
  整理 pixel cluster、有限调色板、轮廓、抗锯齿和抖动等像素画实践。

`Make Your Own Sprites` 官方仓库许可限定研究用途，商业集成需另行取得授权。各项论文方法、开源实现和模型权重在进入产品前分别核对许可证。

## 8. 首版实现范围

首版集中完成六项能力：

1. 人物与宠物主体、关键点和语义区域提取。
2. 32、48、64 三档画布候选与特征格数预算。
3. 区域合并、轮廓简化与重要特征保护。
4. 区域明暗归纳与真实色卡全局选色。
5. 连通域、长条、2×2 拓扑和局部搜索修整。
6. 多候选规则评分与成对偏好记录。
