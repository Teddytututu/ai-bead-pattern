# 数据处理与部署边界

## 图片去向

网页确定性生成在浏览器执行；配置模型路线后，图片经 Demo 服务交给相应模型端点。小程序上传至 Pattern API，由服务端规范化、保存并生成结果。

服务位于远端 SSH 主机时，“本地模型”指该主机上的服务，不表示图片只留在手机或 Windows 电脑。产品客户端使用 /v1/capabilities 展示分析位置；非本机分析端点要求配置 REMOTE_ANALYSIS_LABEL，并显式提交 consentToRemoteAnalysis。

## 保存与删除

Pattern API 默认把图片、任务、会话和结果保存在 services/pattern-api/data，默认保留 24 小时。运行中任务引用的图片受保护；图片删除、任务取消和过期清理由 API 管理。部署时以实际配置及 [API 说明](../services/pattern-api/README.md)为准。

训练标注、教师审核库、导出 JSONL 和冻结快照属于独立研究数据，不套用产品 API 的 24 小时保留期。浏览器草稿不是完整备份；迁移时同时保存图片、标注、版本和哈希。

## 部署

- Demo、教师和模型实验服务用于受控开发环境，通过 SSH 转发访问；不要将整个仓库静态目录公开。
- 产品部署使用 HTTPS、真实微信身份和持久数据卷，关闭模拟登录。
- AppSecret、令牌、连接配置和私钥仅在服务端或个人配置中保存，不写入 Git、前端、截图和公开日志。
- 当前 API 按资源归属校验用户访问；不要以模型端点、网页端口或内容哈希代替认证。
- 参考图纸的来源及使用资格记录随数据保存，下载或人工标注不自动赋予训练和再分发资格。

日志清理不删除活动任务记录或冻结证据。教师备份和恢复步骤见 [Teacher Loop](../tools/teacher-loop/README.md)。
