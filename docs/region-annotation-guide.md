# 眼睛标注：框选、取肤色、填写 prompt、统一封存

2026-10-01。入口：[眼睛标注](http://127.0.0.1:4180/apps/demo/annotation.html)。页面只显示一张完整拼豆格图，原图保持不变。

## 一张图如何完成

1. 在图上拖动鼠标框住一只眼睛；另一只眼再画一个框，允许多个框。框自动对齐格子，可从任意方向拖动。画错可删除对应框或撤销上一个框。
2. 点击“肤色取色器”或“用取色器”，再点击原拼豆图上的肤色格。界面显示实际 RGB 颜色与取样格坐标，取色后自动回到框选模式。取色始终读取原始格子的颜色，不会采到蒙版覆盖层颜色。
3. 填写 prompt，描述眼形、颜色、神态及与周边的关系。可用中文或英文。例如：`Draw dark brown eyes with a small white highlight, matching the face and surrounding bead colors.`
4. 检查这一张图，点击一次“确认全部并封存”。这次点击同时确认**完整拼豆图、全部眼睛蒙版、所选肤色和 prompt**。远端保存成功后自动下一张。

以上内容在同一页面完成，没有分步确认、目标图编辑、逐格占用复核或单独的肤色确认弹窗。框选和取色都只是原图上的标记。封存前可以修改；封存后整条记录固定，只读查看。

没有眼睛、无法确定肤色或不适合标注的图，可以“暂存并跳过”，不将其冒充完成记录。

## 批次与恢复

- 服务器现有 24 张提取格图 JSON，按 20+4 加载。更大的 2,435 张图片 `manifest.jsonl` 是来源清单，不是逐格数据。
- 第 20 张封存成功后自动载入下一批；最后一张封存后停在末尾。下拉框支持回看已封存图纸。
- 浏览器自动暂存每张的框、取色和 prompt；刷新恢复当前批次、图纸和内容。点击“暂存并跳过”、切换样本或批次时先保存草稿。
- 封存失败留在原图，保留框和 prompt，可以重试；服务端对相同内容的封存重试返回原记录，不重复创建。
- 远端版本冲突不会覆盖他人的记录。先在“文件与记录”导出草稿，再点击“重新载入远端版本”。
- “文件与记录”可导入 JSON、导出当前标注、保存草稿或载入远端记录。旧配对页及其数据保留在 `annotation-pair.html`，不自动迁移或封存。

## 封存内容

`eye-annotation-v1` 保存：

- `currentGrid`：完整拼豆格图，作为未修改的目标图来源；
- `eyeBoxes`：每只眼的格坐标矩形，`x/y` 从 0 开始，`width/height` 为覆盖格数；
- `eyeMask`：所有框的并集，全图布尔数组；
- `skinSample`：取样格坐标及该格的颜色 ID；
- `prompt`：本张指令；
- `source`、`sourceOccupancy`：来源、哈希及原有占用证据；
- `confirmation`：显式点击封存的服务端时间，并同时确认 grid、eyeMask、skin、prompt；
- `targetMode: unchanged-source-grid`，不创建人工修改后的目标图。

肤色必须是原拼豆图中实际点选格子的颜色，不能手填一个图外颜色。封存不改变任何原图像素，也不自动把原始未知占用改成有珠。当前图库的采样 RGB、未知占用和来源哈希原样保留；这里的“全部确认”指本次呈现并提交的整条眼睛标注，不生成不存在的逐格占用判断。

后续若用这批数据训练，原格图可作为眼睛重建目标，结合眼睛 mask 与所选肤色构造输入；训练器的数据接入、独立分组和资格审定仍需完成。`trainingEligible` 保持 false，本次不会启动训练。

## 持久保存与接口

默认保存目录为 `output/region-annotations/eyes/`，草稿为 `<id>.json`，最终封存快照为 `sealed/<id>.json`。封存文件原子生成、禁止覆盖，优先于旧草稿读取。旧审核包、原始 JSON 与旧配对记录不重写。重要封存输出仍需定期备份。

环境变量 `EYE_ANNOTATION_DIR` 可以指定独立持久目录；默认使用 `REGION_ANNOTATION_DIR` 下的 `eyes/`。图库沿用 `REGION_ANNOTATION_PACKET`，默认读取冻结审核包的 `packet.json`。

- `GET /api/eye-annotation-dataset?offset=0`：每批 20 张；后续携带 `snapshot=<datasetId>`。
- `GET /api/eye-annotations` 和 `GET /api/eye-annotations/<id>`：列表、草稿或封存内容。
- `POST /api/eye-annotations`：`{action: "save" | "seal", expectedVersion, annotation}`。封存时间与四项确认由服务端生成，不能自行提交已封存状态。

92 项 Demo 单元测试、7 项标注浏览器测试通过。覆盖单画布、多框正反向拖动与缩放坐标、取色、原图不变、统一封存、刷新恢复、封存后禁止修改、保存失败保留草稿，以及 20+4 翻批。测试记录使用隔离目录，不进入真实人工标注数据。
