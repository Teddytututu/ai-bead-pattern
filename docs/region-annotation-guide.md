# SDXL 人工配对标注

2026-10-01。入口为 Demo 顶栏的“人工配对标注”，或通过本机 SSH 转发打开 http://127.0.0.1:4180/apps/demo/annotation.html。

## 这次标什么

只看完整拼豆格图，在格图坐标中画可改区，保留修改前输入，并制作人工确认的修改后完整目标图。原照片／插画不参与蒙版、标注输入或模型条件，也无需为训练补采原照片。

这与旧“部件角色审核”不同：无需逐格标眼白／虹膜角色，直接使用实际材料色绘制正确目标。旧 24 例审核包继续保留，未重写原始预测与审核记录。

## 操作顺序

1. 在工作台选择一份不超过 64×64 的完整格图，点击“人工配对标注”；也可导入工作台格图 JSON。教学样例仅用于练习。
2. 填写样本名称、标注者和区域修改指令。观察另一只眼、脸型和周边颜色，指令只描述格图可确认的修改意图。
3. 用“画可改区域”或矩形框选择区域；使用锁定画笔保护必须保持的格。蒙版只基于拼豆格图，不从原照片分割后映射。
4. 核对肤色色号，点击“确认周边与肤色”。“实际模型输入”预览会显示完整格图及蒙版肤色预填。
5. 选择材料色，在右侧逐格修改目标；也可先把可改区填肤色，再画五官，或导入同尺寸、同色卡的完整目标图。左侧输入保持不变。
6. 填写修改依据，复核眼形、表情、高光、颜色和边界，点击“我已核对目标图”。
7. 点击“保存到远端”。需要文件备份时导出标注文件；目标确认后还可以导出配对目标。

可改区全部填满才能确认目标；周边和锁定格不能改动，已有珠子不能删除。白珠与空板分别保存。擦除蒙版或新增锁定会将新范围外的目标格恢复到输入值，可撤销；撤销后需重新确认。

## 进度与保存

- 浏览器暂存自动保存当前工作区，刷新可恢复；浏览器隔离、端口变化或清理缓存会影响暂存。
- “保存到远端”写入持久项目目录 output/region-annotations/。只有页面明确显示远端保存成功才算服务端落盘。
- 远端记录带版本号；其他窗口已保存更新时返回冲突，不覆盖。先导出本窗口草稿，再载入远端最新记录处理。
- 每次保存已确认目标时，另外保留 reviewed/ 中的版本快照。草稿不会被自动算作人工真值。
- 远端列表可载入不同样本。切换前如有未保存修改，会提示先保存或导出。
- 输入格图对同一记录保持不可替换；更换输入需创建新标注。输出仍需定期备份，不能只依赖浏览器。

## 配对格式与边界

region-annotation-v1 保存完整输入 currentGrid、目标 targetGrid、全图 editMask/lockedMask、肤色、prompt、人工确认、分组和来源记录。conditioning 固定 bead-grid-only；拒绝原图参考字段。

region-training-pair-v1 将已确认标注导出为 region-generation-v3 请求与完整目标格图，训练监督保留正确五官，不把肤色底图当监督目标。导出不会执行 SDXL，也不会开始训练。

分组和使用范围可以保留待确认，不妨碍先做目标图。trainingEligible 保持 false；独立训练／验证切分与数据集质量门禁另外审定。训练器接入真实人工配对数据仍是后续工作。

## 验证

前端与 API 共用格图、蒙版和目标校验。自动化在隔离测试存储中验证画笔、范围／锁定保护、先确认后修改、导出、刷新恢复、远端保存与并发版本冲突、原图字段拒绝和窄屏布局。自动测试记录不进入真实标注目录。
