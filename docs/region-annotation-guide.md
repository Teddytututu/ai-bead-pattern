# 独立眼睛训练标注

入口为 /apps/training-annotation/，通过 Demo 的 SSH 转发访问。旧 /apps/demo/annotation.html 跳转到此页面。该页面标记完整拼豆格图上的目标，不调用模型替代人工标注。

## 操作

1. 加载完整格图；每只眼画一个格对齐框，可添加多个框、删除或撤销。
2. 用肤色取色器点击原图珠格。颜色从原始格图读取，不读取蒙版覆盖色。
3. 填写描述眼形、颜色和表情的 prompt。
4. 检查整图、全部框、肤色和 prompt，点击“确认全部并封存”。
5. 远端保存成功后进入下一张；不适合的样本暂存并跳过。

封存前可以修改，封存后只读。封存失败留在当前图，保留草稿；重复提交相同封存不会创建重复记录。版本冲突需要重新读取，不能覆盖他人的修改。

## 批次和保存

图库按 20 张一批加载，末批可以不足 20 张。实际可用条目由服务器格图索引决定；原始图片 manifest 不能替代逐格 JSON。

切换、跳过与刷新保留浏览器草稿，远端封存才是持久记录。默认眼睛记录位于 output/region-annotations/eyes，可由 EYE_ANNOTATION_DIR 设置，或继承 REGION_ANNOTATION_DIR 下的 eyes 子目录。

保存内容包含完整格图、眼睛目标蒙版、肤色、prompt、内容版本和来源。新记录的 maskPurpose 为 training-target，遵循 eye-annotation-v1；旧记录按原契约读取，不重算已有哈希。

## 与产品蒙版的区别

| 项目 | 产品工作台 | 训练标注 |
| --- | --- | --- |
| 蒙版目的 | region-guidance，指定本次生成范围 | training-target，明确人工目标 |
| 操作 | 主体圈选、局部生成和候选接受 | 框选、取色、描述及封存 |
| 模型调用 | 可调用 SAM2／SDXL | 不调用模型替代目标 |
| 保存结果 | 当前图纸及生成回放 | 独立目标记录 |

工作台的内部入口可以带出完整格图重新标注，不继承辅助框或自动确认。产品回放不直接成为训练真值，封存也不自动表示已满足来源资格和数据划分要求。

原图到卡通图的 A/B 选择使用另一套 [教师审核](../apps/teacher-review/README.md)。它与眼睛标注共同服务研究，但都不是已经完成的第二阶段全图配对数据集。
