# 精读方法

## 资料范围

研究覆盖 Lospec 教程目录、像素画艺术家文章、论坛长帖、YouTube 教程字幕、Aseprite 与 Pixelorama 官方文档，以及像素化、量化、抖动、缩放和图块工具的 GitHub README。

候选阶段共采集：

- Lospec 目录 586 条
- 主题视频 720 条
- Lospec 与主题搜索合并后的唯一视频 927 条
- Aseprite 与 Pixelorama 文档 62 页
- GitHub 定向仓库 29 个

最终记录收窄到 511 条。来源需要具备正文、完整字幕、官方页面主体或完整 README，并通过主题相关性、长度、锚点和重复项检查。

## 单条记录字段

每条记录包含：

1. 标题、作者、来源、URL、类型、语言和日期
2. 具体技巧与操作步骤
3. 适用对象与画布尺度
4. 常见症状与修正方法
5. 段落、章节或字幕时间锚点
6. 拼豆算法阶段、规则和优先级
7. 来源质量等级与访问状态

## 精读过程

1. 抓取公开正文、字幕、文档或 README。
2. 清理导航、滚动字幕重复行和页面模板文本。
3. 按段落、README 标题或 30 至 45 秒字幕窗口分段。
4. 使用词边界匹配定位轮廓、像素簇、配色、光照、材质、图块、动画等技术段落。
5. 提取操作性最强的段落，并保留原文定位。
6. 将技巧映射到拼豆结构、色板、网格、修整、导出或评价阶段。
7. 执行 JSON Schema、URL 唯一性、CSV 行数和锚点完整性检查。

## 证据说明

- `techniques`、`workflow_steps` 和 `anchors` 保留原文表达，方便回看上下文。
- `failure_modes` 中带“方法归纳”的内容来自同篇资料的方法方向与主题规则。
- `bead_mapping` 属于产品设计推导，服务于算法实现与验收。
- 自动字幕存在口误和识别误差；关键产品规则采用多来源交叉支持，并优先引用文章、官方文档和清晰字幕。

## 去重

- URL 规范化后相同的条目合并。
- YouTube 地址保留视频 ID。
- 同一内容的转载、镜像和翻译版本优先保留原始发布页。
- 系列教程每集承担独立主题时分别计数。
