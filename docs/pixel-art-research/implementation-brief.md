# 像素画研究实现清单

## 目标顺序

511 条精读资料支持以下生成顺序：

1. 主体剪影与连通结构
2. 眼睛、嘴、耳尖、发型、花纹和道具端点
3. 亮、中、暗区域顺序
4. 实体色板映射
5. 像素簇与轮廓节奏
6. 纹理、抖动和装饰
7. 制作复杂度

候选评分沿用同一顺序。结构和身份特征拥有最高权重，色差与装饰承担让步空间。

## P0 实现

### 1. 透明细线与轮廓保持

模块：

- `packages/pattern-core/src/shape.ts`
- `packages/pattern-core/src/pipeline.ts`

动作：

- 将源图中的高置信细线、闭合轮廓和端点映射为稀疏边界锚点。
- 形状缩放时优先分配锚点附近的目标格。
- 颜色精修阶段允许锚点周围换色，形状占用保持稳定。
- 透明线稿沿专用细线保护路径进入候选生成。

验收：

- 透明单像素线稿在 `32 / 48 / 64` 三档均保持主要连通路径。
- 投影边界锚点保留率进入自动测试。
- 闭合孔洞、独立组件和端点方向保持。

### 2. 身份关键点落格

模块：

- `packages/pattern-core/src/planning/feature-placement.ts`
- `packages/pattern-core/src/pipeline.ts`
- `packages/pattern-core/src/planning/candidate-evaluation.ts`

动作：

- 双眼共享基线、间距范围和角色颜色。
- 嘴线长度、倾斜和脸部承载区域共同约束候选。
- 耳尖、发梢、鼻尖、宠物花纹和道具端点进入高权重特征集合。
- 目标尺度控制模板层级：小网格保留特征暗示，大网格启用瞳孔、高光和局部色阶。

验收：

- 双眼碰撞数量为零。
- 硬特征完整可见率、Top-2 接受率和对称误差进入 Gate 报告。
- 普通上传拥有真实执行的特征规划诊断。

### 3. 明度顺序

模块：

- `packages/pattern-core/src/planning/value-planner.ts`
- `packages/pattern-core/src/planning/palette-planner.ts`

动作：

- 每个主体区域先建立 `shadow / base / light` 角色。
- 实体色候选先满足 `L_light > L_base > L_shadow`，随后比较色差。
- 人脸与头发、眼睛与皮肤、主体与背景设置独立最小明度间隔。
- 同一来源区域共享明度角色族，减少局部明暗跳变。

验收：

- 三个明度角色保持严格顺序。
- 区域间最小明度差进入候选指标。
- 低色数输入仍保持主体层次。

### 4. 像素簇与轮廓节奏

模块：

- `packages/pattern-core/src/grid-refinement.ts`

现有基础：

- 孤立格、单格色带、棋盘纹、对称性和语义保护格代价。
- `quality` 模式已加入 3×3 邻域环段代价，用于合并碎裂同色簇。

后续动作：

- 输出细化前后的碎裂环段、小连通域和单格色带数量。
- 强边界、尖角和语义端点降低平滑权重。
- 弱颜色证据区域允许轮廓整理，高重要度区域提高数据保持权重。

验收：

- `quality` 模式在碎裂轮廓夹具上降低总能量和环段碎裂数量。
- 语义保护格保持原颜色。
- 代表性最大负载维持交互预算。

## P1 实现

### 选择性描边

- 背光侧采用深色轮廓。
- 受光侧采用较亮轮廓。
- 主体与背景明度差充足时开放局部边缘。

### 抖动预算

- 人脸、眼睛、文字和轮廓使用低预算。
- 天空、水面和大面积渐变使用中预算。
- 预算同时约束抖动格占比、颜色切换次数和孤立豆数量。

### 制作复杂度

- 指标覆盖总色数、替代色、颜色切换、豆数、小组件和长细结构。
- 入门模式提高连通性与大色块权重。

## 实施顺序

1. 为透明细线失败样本写回归测试。
2. 完成边界锚点与细线占用保持。
3. 为人物五官和宠物花纹补真实样本测试。
4. 完成明度顺序与区域间隔约束。
5. 暴露像素簇诊断并校准 `quality` 权重。
6. 用固定真实图片集比较结构、身份、明度、色差和制作成本。

每一步保持独立提交，并运行核心测试、类型检查、构建和真实图片对照。
