# 像素画技巧到拼豆产品规则

## 1. 产品目标顺序

拼豆图纸生成采用分层目标：

1. 主体结构和剪影
2. 身份关键点
3. 主明暗区域
4. 实体色板映射
5. 轮廓节奏和像素簇
6. 材质、纹理和装饰
7. 制作复杂度

这套顺序来自 511 条资料中的共同规律。调色板与明度出现 402 次，人物与角色 277 次，光照与体积 240 次，轮廓与像素簇 125 次。

## 2. 算法阶段

| 阶段 | 输入 | 关键规则 | 输出 |
|---|---|---|---|
| A. 目标规格 | 图片、网格、色板、用途 | 先锁定画布与细节预算 | `CanvasPlan` |
| B. 主体分析 | 图像、mask、关键点 | 生成语义重要度和身份特征 | `ImageAnalysis` |
| C. 大形规划 | mask、边缘、明度 | 建立剪影和主区域 | `StructurePlan` |
| D. 明度规划 | 区域图、光照 | 先确定亮中暗顺序 | `ValuePlan` |
| E. 色板规划 | 实体 Lab 色板、区域 | 明度顺序优先，色差其次 | `PalettePlan` |
| F. 网格采样 | 结构、颜色、目标格 | 结构引导的区域采样 | 初始 `PatternGrid` |
| G. 像素簇修整 | 初始网格 | 清理孤立点、色带和轮廓节奏 | 精修网格 |
| H. 制作检查 | 精修网格、库存 | 统计豆数、连接、替代色和分区 | 图纸与物料表 |

## 3. P0 规则

### 3.1 目标尺度决定细节预算

建议增加：

```ts
interface ArtConstraintProfile {
  targetWidth: number;
  targetHeight: number;
  detailBudget: "icon" | "sprite" | "portrait" | "scene";
  maxColors: number;
  outlineMode: "solid" | "selective" | "open";
  ditherBudget: number;
  minFeatureArea: number;
  minFeatureWidth: number;
}
```

规则：

- `icon` 保留剪影、主色和一个身份符号。
- `sprite` 保留姿态、脸部暗示和服装大块。
- `portrait` 保留双眼、发际线、脸型和局部色阶。
- `scene` 保留景深、焦点和主要遮挡关系。

验收：同一输入在 `32 / 48 / 64` 网格上呈现逐级增加的细节，主体比例保持稳定。

### 3.2 结构先于平均颜色

每格候选颜色的代价建议包含：

```text
E = w_structure * E_structure
  + w_feature   * E_feature
  + w_value     * E_value
  + w_color     * E_color
  + w_cluster   * E_cluster
  + w_craft     * E_craft
```

建议顺序：`w_structure >= w_feature > w_value > w_color`。

验收：眼睛、耳朵、发型外沿、宠物花纹和道具轮廓获得更高保留率；背景纹理承担主要压缩。

### 3.3 明度顺序约束

区域映射前先建立亮、中、暗三组。实体色映射保持区域明度次序：

```text
L_highlight > L_midtone > L_shadow
```

色差最小化只在满足明度顺序的候选中进行。

验收：主体与背景、眼睛与皮肤、头发与脸部保持预设最小明度差。

### 3.4 像素簇代价

建议加入四项：

- 孤立格数量
- 一格宽长条数量
- 小连通域数量
- 平行色带长度

保留列表包含瞳孔、鼻尖、星点、铆钉等语义单格。

验收：清理后语义单格保持，装饰性孤立格下降，主体轮廓和关键特征保持。

### 3.5 轮廓节奏

轮廓转为水平和垂直 run length 序列，惩罚局部突变：

```text
E_contour = sum abs((r[i+1] - r[i]) - (r[i] - r[i-1]))
```

尖角、耳尖、发梢和武器端点通过语义标签降低惩罚。

验收：圆弧和脸部外沿的阶梯变化更平顺，尖锐特征保持方向感。

### 3.6 身份关键点

人物和宠物采用成对特征与局部模板：

- 双眼共享基线和间距范围
- 瞳孔与高光按目标尺度逐级启用
- 嘴线长度和倾斜受脸型约束
- 耳朵、发型和花纹进入高权重区域

验收：关键点误差、双眼对称误差和局部对比进入单独指标。

## 4. P1 规则

### 4.1 选择性描边

轮廓颜色读取主光源与邻接区域：

- 背光侧使用深色轮廓
- 受光侧使用较亮轮廓
- 主体与背景明度差足够时开放局部边缘

验收：主体外轮廓连续，内部描边数量随网格缩小而下降。

### 4.2 抖动预算

`ditherBudget` 表示允许进入规则抖动的格子占比。

- 人脸、眼睛、轮廓和文字区域使用低预算
- 天空、水面和大面积渐变使用中预算
- 拼豆入门模式采用更低预算

验收：抖动呈稳定图案，孤立豆和颜色切换次数处于预算内。

### 4.3 材质模板

材质模板只控制纹理方向、对比和密度：

| 材质 | 规则 |
|---|---|
| 金属 | 窄亮带、高对比、环境反射色 |
| 木材 | 沿长度方向的成组线条 |
| 石头 | 面状转折、裂纹方向和集中高光 |
| 土壤 | 团块纹理和低频明暗变化 |
| 水面 | 水平反射带和远近密度变化 |
| 布料 | 褶皱沿受力方向展开 |

验收：纹理集中在高置信区域，主体轮廓和关键点周围保持清楚。

### 4.4 图块接缝检查

地图与重复背景模式增加：

- 左右边界一致性
- 上下边界一致性
- 内角、外角和过渡状态覆盖
- tile 变体边界兼容性

验收：平铺预览中高对比接缝数量为零。

## 5. P2 规则

### 5.1 风格配置

建议提供三种美术配置：

| 配置 | 特征 |
|---|---|
| 清晰 | 大色块、低抖动、强轮廓、少颜色 |
| 细腻 | 更多色阶、选择性描边、局部材质 |
| 复古 | 限色色板、规则抖动、硬边和平台色板倾向 |

### 5.2 动画关键帧转静态图

视频、GIF 或 sprite sheet 输入先计算每帧：

- 剪影清晰度
- 主体面积
- 关键点可见度
- 运动模糊和遮挡

选择得分最高的关键帧生成拼豆图纸。

## 6. 产品控件

用户界面建议提供：

- 网格尺寸：`32 / 48 / 64 / 自定义`
- 细节等级：图标、角色、头像、场景
- 色数上限
- 轮廓模式：实线、选择性、开放
- 纹理强度
- 抖动强度
- 关键特征保护开关
- 制作简化强度

高级参数留在调试和实验界面，主流程保持少量清楚选择。

## 7. 评价指标

| 指标 | 目标 |
|---|---|
| silhouette IoU | 主体大形 |
| landmark retention | 眼睛、嘴、耳朵、发型和道具 |
| contour rhythm | 阶梯平顺度与尖角保留 |
| value-order accuracy | 区域明度顺序 |
| palette ΔE | 实体颜色匹配 |
| cluster coherence | 小连通域、孤立格和色带 |
| craft complexity | 色数、切换次数、豆数和长细结构 |
| preference score | 人工偏好与主体辨识度 |

评价先看结构与辨识度，再看色差和制作成本。

## 8. 代码落点

建议与现有 `pattern-core` 结构对应：

| 规则 | 模块 |
|---|---|
| 尺度与细节预算 | canvas planner / adaptation |
| 身份关键点 | feature planning |
| 明度顺序 | value planning / palette planning |
| 结构引导采样 | image guidance / pipeline |
| 像素簇与轮廓 | grid refinement / shape |
| 制作复杂度 | evaluation / export |

本轮代码整合优先选择独立、低风险的像素簇与轮廓规则，保持现有主体分析和色板规划接口稳定。

## 9. 已进入产品的规则

`quality` 网格细化增加 3×3 邻域环段代价。同色邻居围绕中心分成多段时提高能量，引导弱颜色差区域形成连续像素簇；语义保护格继续锁定，`fast` 模式保持原有计算量。

回归测试覆盖近似颜色下的碎裂轮廓，并验证细化后环段碎裂数量与总能量同步下降。
