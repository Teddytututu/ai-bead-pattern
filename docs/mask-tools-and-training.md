# 工作台蒙版与训练目标标注

2026-10-01 用户确认：两处分开，工作台蒙版用于辅助确定区域；标注端蒙版用于确定性标注目标。

## 产品工作台

入口：`/apps/demo/` 左侧“蒙版”。

- **圈选主体**：保留现有圈选 → SAM 2 贴合 → 确认后重新生成流程。
- **眼睛蒙版**：蒙版工具的子功能，带入当前完整拼豆格图，在格坐标中分别框选眼睛或补充辅助区域，再确认周边、肤色和生成条件后进行局部生成。
- 眼睛工具有“格图与辅助蒙版／模型输入／生成候选”视图，可用取色器选择原格图颜色。辅助框只定位本次处理范围；接受候选前不改当前图纸。
- 模型生成仍使用已有 `region-generation-v3` 的周边确认、肤色底图、范围保护与完整填充校验。候选质量需人工判断，并保留接受／拒绝、撤销和导出。
- 产品回放显式记录 `maskPurpose: region-guidance`，不是训练样本封存，也不写训练标注 API。

最终工作台默认不显示训练数据操作。开发者使用 `?internal=1` 时，可以带出格图到独立训练页；它不属于产品蒙版工具。

## 独立训练标注前端

入口：`/apps/training-annotation/`；源码在 `apps/training-annotation/`。它有自己的 HTML、样式、交互状态和标注契约，复用远端静态服务与保存 API。旧 `/apps/demo/annotation.html` 仅做兼容跳转，原浏览器草稿和服务端记录继续可用。

- 一张完整拼豆格图，每只眼一个框，可多框；
- 取色器直接点肤色，填写 prompt；
- 人工点击一次确认全部并封存，固定图纸、眼睛目标蒙版、肤色与 prompt；
- 不调用 SAM 2 或 SDXL 来替代人工定义的目标，不提供生成、接受候选等产品功能；
- 新标注显式记录 `maskPurpose: training-target`，用于确定性标注目标。旧版本未带此字段的已保存记录仍按原契约读取，不回写或重算封存文件。

独立前端继续支持 20+4 批次、跳过草稿、版本冲突保护、刷新恢复和持久封存，详见[训练标注说明](region-annotation-guide.md)。

## 数据边界

| 内容 | 工作台 | 训练标注端 |
| --- | --- | --- |
| 蒙版含义 | 辅助确定本次生成区域 | 明确指定标注目标 |
| 原图 | 在接受生成候选前保持 | 始终保持，不人工改目标图 |
| 确认作用 | 冻结本次推理上下文 | 统一确认并封存整条标注 |
| 协议 | region-generation-v3／region-generation-review-v3 | eye-annotation-v1 |
| 用途字段 | region-guidance（回放） | training-target（新标注） |
| 保存 | 生成回放及格图导出 | output/region-annotations/eyes |
| 训练资格 | 不产生训练真值 | 封存不自动授予训练资格 |

工作台拒绝将训练标注或训练配对文件直接作为生成辅助文件导入；训练端拒绝 `region-guidance` 用途字段。只允许显式带出完整格图重新人工标注，不继承工作台候选、辅助框或自动确认。

这次是前端分工、产品入口和数据边界整理，不代表生成眼睛质量已通过全部门禁。训练保持停止。
