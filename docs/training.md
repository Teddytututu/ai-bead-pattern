# 两阶段训练路线

本页区分当前实现与下一步设计。阶段一由教师任务独立推进；产品主生成器仍是确定性算法。安装环境、一次优化器更新或合成烟测不代表正式模型已训练完成。

## 任务与实现状态

| 阶段 | 输入 → 输出 | 当前实现 |
| --- | --- | --- |
| 第一阶段教师 | 高清原图 → 256×256 卡通中间图 | SDXL、Canny 条件、A/B 审核、冻结快照和风格 LoRA 工具 |
| 第一阶段学生 | 高清原图 → 256×256 卡通中间图 | 训练目标已明确；尚无接入产品并完成评测的学生模型 |
| 第二阶段 | 256×256 卡通图 → 32×32／64×64 拼豆网格 | 确定性采样、结构、材料配色和精修可复用；配对监督的全图网格网络尚未实现 |
| 可选局部实验 | 完整格图＋编辑区 → 局部候选 | SDXL 区域生成 v3；不承担第二阶段全图网格预测 |

五官规则模板已删除，不作为任何阶段的基线回退或可选修正。

## 第一阶段已有工具

[Teacher Loop](../tools/teacher-loop/README.md)保存原图、A/B 卡通图、人工选择、拒绝原因、来源分组及内容哈希。内部高分辨率底稿与 256 图都保留，输出等比缩放和补边。

当前教师训练是目标图＋文字的风格 LoRA。原图不是其 UNet 的配对输入条件，Canny 用于推理。原图与人工通过的目标可供后续条件模型或学生训练使用，不能把风格 LoRA 训练直接称为配对学生训练。

## 第二阶段待实现设计

下一步应先建立明确的配对任务：256 卡通输入、人工确认的 32／64 网格目标、占用状态、材料色卡版本和空间变换。32 与 64 是不同表达尺度，不能直接把 64 目标缩小后当作已经审定的 32 真值。

建议优先验证直接监督的网格预测路线，复用现有材料映射、合法性检查、质量评测、API 和导出。网络结构、是否使用预训练编码器及 adapter、损失权重和部署格式仍需实验确定。尚未实现这些模块，也没有可以报告的训练准确率。

重新使用 SDXL 做全图转换需要单独对照：比较身份、五官位置、姿态、颜色和空间对应是否发生额外变化。局部修复服务已经存在，不意味着它能够稳定完成全图第二阶段。训练 adapter 本身不保证语义对齐。

## 配对数据要求

- 每条记录固定输入与目标哈希、源设计分组、目标格数、色卡内容版本、占用和坐标变换。
- 输入必须是实际中间图；评测同时覆盖教师输出和未来学生输出，观察阶段间分布变化。
- 全图语义、轮廓、五官与姿态需对应。只有风格相似的两张图不能充当配对监督。
- 白珠与空板分开记录；无法确认的目标不填成确定标签。
- 相同设计的镜像、改色和近似版本先归组，再划分训练、验证和测试。
- 成品图纸参考集、人工眼睛框和教师卡通输出各自提供部分信息，当前不能直接拼成完整第二阶段配对数据集。

## 验收与手机接入

先固定现有确定性基线，再分别报告 32／64 格的轮廓、身份、五官位置、占用、色差、色数、碎片和人工接受率。失败样本计入分母；推理延迟、内存和模型大小需在目标设备实际测量。

手机通过现有 API 可以调用服务端生成。手机本地神经推理尚未交付；学生或网格模型导出、量化、运行时适配及真机验证属于后续工作。没有实测前，不给出手机速度、质量提升比例或准确率承诺。
