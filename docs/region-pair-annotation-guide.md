# 旧版 SDXL 人工配对标注（保留记录入口）

2026-10-01。入口为 Demo 顶栏的“人工配对标注”，或通过本机 SSH 转发打开 http://127.0.0.1:4180/apps/demo/annotation-pair.html。

## 这次标什么

只看完整拼豆格图，在格图坐标中画可改区，保留修改前输入，并制作人工确认的修改后完整目标图。原照片／插画不参与蒙版、标注输入或模型条件，也无需为训练补采原照片。

这与旧“部件角色审核”不同：无需逐格标眼白／虹膜角色，直接使用实际材料色绘制正确目标。旧 24 例审核包继续保留，未重写原始预测与审核记录。

## 操作顺序

1. 打开页面会自动读取服务器首批 20 张格图 JSON；有浏览器草稿时保留并恢复它。图库样本先填写标注者、复核完整范围与逐格占用，再点击“我已核对格图与全部占用”。也可从工作台带入不超过 64×64 的完整格图或手动导入 JSON；教学样例仅用于练习。
2. 填写样本名称、标注者和区域修改指令。观察另一只眼、脸型和周边颜色，指令只描述格图可确认的修改意图。
3. 用“画可改区域”或矩形框选择区域；使用锁定画笔保护必须保持的格。蒙版只基于拼豆格图，不从原照片分割后映射。
4. 核对肤色色号，点击“确认周边与肤色”。“实际模型输入”预览会显示完整格图及蒙版肤色预填。
5. 选择材料色，在右侧逐格修改目标；也可先把可改区填肤色，再画五官，或导入同尺寸、同色卡的完整目标图。左侧输入保持不变。
6. 填写修改依据，复核眼形、表情、高光、颜色和边界，点击“我已核对目标图”。
7. 点击“保存到远端”。需要文件备份时导出标注文件；目标确认后还可以导出配对目标。

可改区全部填满才能确认目标；周边和锁定格不能改动，已有珠子不能删除。白珠与空板分别保存。擦除蒙版或新增锁定会将新范围外的目标格恢复到输入值，可撤销；撤销后需重新确认。

## 服务器图库与批次

目前服务器有 24 张已提取的逐格 JSON，队列为首批 20 张、第二批 4 张。来源是旧冻结审核包中的格图数据；原包、原有审核结果和哈希保持不变。更大的 2,435 张图片清单 `manifest.jsonl` 只记录图片来源与文件信息，不包含逐格材料与占用，不能直接当作格图导入。因此这次使用现有格图 JSON，无需另找格式相同但来源不明的数据。

- 页面显示批次、总数和当前位置，可用下拉框选择本批文件。
- “下一张”“保存并下一张”走到第 20 张后会自动读取下一批。最后一张保存后停在末尾，不循环覆盖。
- 切换前先将当前修改保存到远端。保存失败或有版本冲突时停留当前文件；切换前后的草稿也分别在浏览器暂存。
- 刷新恢复当前批次和样本。有独立导入或工作台草稿时，图库不会覆盖它；点击“打开本批”进入队列。
- 无法读取的 JSON 会显示错误，仍占据原队列位置；不会静默丢弃样本。

### 输入格图先复核

这 24 张 JSON 保存了尺寸、逐格 RGB 与占用，但现有占用全部为未知。采样 RGB 并不等于已经匹配品牌材料，也不代表读格质量已经通过人工验收。

1. 检查格点、尺寸、完整图案和采样颜色；读格错误的样本先跳过。
2. 橙点表示占用未知。在左侧输入图选择“有珠／空板／未知”逐格修改。
3. 如图案有明确空板色，可点击“点空板颜色初填占用”，再点一个空板格；它把同色格暂设为空板、其余设为有珠。随后必须检查并恢复同色白珠。“全图暂设为有珠”同样只是初填。
4. 全部未知格处理完、填写标注者后才能确认输入。确认前不能确认周边或修改目标；确认后输入固定，再按“先周边，再蒙版区”标注目标。

输入修正另存到新标注记录，绝不回写旧冻结包。空板是 `-1`，白珠保留颜色索引；未经人工确认的 RGB 格图不能作为最终真值。

## 进度与保存

- 浏览器暂存自动保存当前工作区，刷新可恢复；浏览器隔离、端口变化或清理缓存会影响暂存。
- “保存到远端”写入持久项目目录 output/region-annotations/。只有页面明确显示远端保存成功才算服务端落盘。
- 远端记录带版本号；其他窗口已保存更新时返回冲突，不覆盖。先导出本窗口草稿，再载入远端最新记录处理。
- 每次保存已确认目标时，另外保留 reviewed/ 中的版本快照。草稿不会被自动算作人工真值。
- 图库批次切换会先保存修改；独立导入、教学样例或远端记录列表的替换操作仍会提示处理未保存修改。
- 同一记录不能替换输入来源；图库输入确认前只允许复核占用，保留原始采样格图。输入确认后不可替换；换图需创建新标注。输出仍需定期备份，不能只依赖浏览器。

## 配对格式与边界

region-annotation-v1 保存完整输入 currentGrid、目标 targetGrid、全图 editMask/lockedMask、肤色、prompt、人工确认、分组和来源记录。conditioning 固定 bead-grid-only；拒绝原图参考字段。图库样本额外保存 inputReview：来源哈希、原始采样格图、逐格 0／1／null 占用和人工确认状态。

region-training-pair-v1 将已确认标注导出为 region-generation-v3 请求与完整目标格图，训练监督保留正确五官，不把肤色底图当监督目标。导出不会执行 SDXL，也不会开始训练。

分组和使用范围可以保留待确认，不妨碍先做目标图。trainingEligible 保持 false；独立训练／验证切分与数据集质量门禁另外审定。训练器接入真实人工配对数据仍是后续工作。

## 验证

前端与 API 共用格图、蒙版和目标校验。自动化在隔离测试存储中验证画笔、范围／锁定保护、先确认后修改、导出、刷新恢复、远端保存与并发版本冲突、原图字段拒绝和窄屏布局。自动测试记录不进入真实标注目录。


## 服务配置

默认只读索引为 `output/template-learning/ft1-preannotation-v1/pilot/review/packet.json`，可用环境变量 `REGION_ANNOTATION_PACKET` 指定另一份同结构索引；设置为空字符串可关闭自动图库。API 为 `GET /api/annotation-dataset?offset=0`，偏移按 20 递增，后续请求携带首批 `datasetId` 作为 `snapshot`，防止读取期间索引变化造成跳样本。

本轮验证：89 项 Demo 单元测试、5 项标注浏览器测试通过，覆盖 20+4 翻批、末尾、刷新恢复、保存失败不切换，以及占用确认与来源保护。测试使用隔离标注目录，不产生真实人工记录。
