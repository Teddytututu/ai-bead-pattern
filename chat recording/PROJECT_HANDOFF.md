# 拼豆图纸生成器：需求与算法交接

归档日期：2026-09-08。来源：2026-08-15 至 09-05 的用户历史要求及检索摘要；2026-09-08 读取的[仓库 README](../README.md)。本文件保存适合公开的产品、算法与工程知识。历史搜索返回部分结果，归档覆盖本次成功读取的记录。

## 产品目标

照片转为可实际制作的拼豆网格图纸，保留主体特征，使用真实材料色卡，并满足手工工艺与库存约束。首发原生微信小程序 + TypeScript；底层 Material Palette + Grid Pattern 支持扩展到十字绣、钻石画、马赛克。

2026-08-15 用户强调遵循人类作画过程：结构、五官与比例优先；固有色与阴影分开；兼顾真实色卡、审美配色、边缘处理；重点解决相邻区域同色粘连、竖条、细碎边缘等问题。

研究讨论中的方法映射：PIA 用于结构和重要度；MYOS 用于格结构和边缘；SD-πXL 用于离散有限色卡。上述为历史方法建议，具体采用情况由代码与实验核实。生成主流程以视觉证据、确定性优化及偏好学习组合实现。

## 当前仓库文档描述的实现

README 记录 pattern-core v0.7.0：
CanvasPlan → FeaturePlacement → StructurePlan → ValuePlan → PalettePlan → Unified Grid Refinement → Preference Aggregation。

人物五官先确定离散格位；语义区域合并与重映射；区域 light/base/shadow/outline 角色映射到真实色号；Fast/Quality 两档整理孤立格、细条、棋盘锯齿与双眼对称；A/B/Tie 通过 Bradley–Terry 聚合排序。此段属于文档现状，运行状态应通过对应测试、模型日志和产物确认。

多来源视觉证据保存独立置信度、provenance 和稳定 identity。大型 mask/importance map 采用流式数值指纹；语义等价的输入规范化后生成相同 identity。

主体交互：沿主体外侧粗圈；BiRefNet 基础主体与连通组件选择；添加/擦除用于局部微调；识别、补充、擦除和圈选分色显示；画布按原图比例 contain；草稿与确认分开；确认后触发一次完整生成；重新打开保留操作。MaskEditSession 用历史和 cursor 支持撤销、重做与分支编辑，确认追加 mask-editor 来源及稳定 revision。主体占位与语义区域证据分别管理。

偏好标注入口收在 `?internal=1`，普通页面重点展示图纸、候选与材料信息。

## 核心工程约定

- 图像到图纸、色彩映射、网格优化、PNG/PDF 导出、材料统计与合规共同构成交付范围。
- Lab/CIEDE2000 与真实有限色卡配合；全局材料子集、角色分配与库存一并检查。
- 长方形图保持比例，裁剪或居中留白随目标方案决定。
- 主体轮廓、连通块、孔洞、关键点与身份花纹重点保护。
- 原图坐标、原图像素半径和网格半径明确区分。
- 已制作格锁定与剩余图案重排保持一致。
- 评价按来源图片划分，保留候选生成配置、视觉来源、置信度与评分贡献。
